무료 AI를 업체를 골라 주는 도구가 아니라 질문지·기록표·비교표·메시지를 만드는 정리 비서로 씁니다. 두 사람 프로필 → 총예산·역산 일정 → 같은 질문 견적 → 기본·선택·추가 비용 펼치기 → 계약 전 위약금·환급 문장 확인 → 지출·잔금 기록까지 순서대로.
계약 내용은 업체 계약서와 공식 고시·표준약관 원문, 결정은 두 사람입니다.

  • 박람회에서 '오늘만 혜택'이라는 말에 계약금을 먼저 냈다

웨딩 견적·계약 셀프 정리 순서

기준 세우기 — 두 사람 프로필 10줄, '꼭 / 있으면 좋음 / 없어도 됨' 우선순위와 양가 의견 정리, 항목별 상한이 있는 총예산 메모, 예식일 기준 역산 일정표.
후보 찾기 — 업체 누리집·참가격의 가격·위약금 표시를 같은 칸에, 박람회 가기 전 두 사람 합의, 기본·선택을 나눈 견적 요청 메시지, 카페 글·지인 이야기를 '확인 질문'으로 바꾸기.
견적·상담 — 모든 곳에 같은 견적 질문지, 상담 직후 기록표, 견적서를 기본·선택·물어볼 것 3칸으로 펼치기, 최종 예상 총액 비교표(1등·추천 없음).
계약 전·계약 후 — 계약서 표지의 중요정보 표시 확인, 표준약관과 대조할 질문, 위약금·환급 문장 그대로 정리와 날짜 3개, 두 사람 30분 결정, 지출·잔금 기록, 추가요금 대응, D-30 점검, 본식 후 정산.

꼭 알아 두세요
· AI는 업체를 고르거나 위약금을 계산하지 않습니다. 계약 내용은 업체 계약서, 표준약관·고시는 공정거래위원회 원문, 계약 해지·위약금 분쟁은 소비자상담센터(1372)가 기준입니다.
· 이 키트는 어떤 기관·웨딩 업체·플랫폼과도 관련이 없습니다.
· 이름·연락처·주민등록번호·계좌번호·계약서 사진 원본은 AI에 넣지 않는 방식입니다.
· 평균 비용·위약금 비율 같은 숫자는 싣지 않습니다. 본문 사람·업체·금액 예시는 모두 가상입니다.

자주 묻는 질문

AI가 우리에게 맞는 웨딩홀을 골라 주나요?
아니요. 같은 질문지와 최종 총액 비교표로 빠진 답과 추가 가능 비용을 찾게 돕고, 결정은 두 사람이 합니다.
위약금도 계산해 주나요?
아니요. 위약금·환급 기준은 업체 계약서에 있고 표준약관 사용 여부도 업체마다 다릅니다. 계약서 문장을 그대로 정리하고 1372에 물을 자료를 준비하는 방법을 드립니다.
이미 계약했어요.
위약금 문장 정리(T15)와 지출·잔금 기록부터 시작하시면 됩니다.

결제 후 등급별 zip 파일을 받습니다. 개인 사용 목적이며 재판매·무단 배포는 금지됩니다.
