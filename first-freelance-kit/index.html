'알아서 잘'이 아니라
범위서·견적서로

무료 AI를 계약을 판단하는 도구가 아니라 범위서·견적서·메시지 초안과 확인 질문을 만드는 비서로 씁니다. 내 가격 계산 → 문의 분석 → 포함·제외 범위서 → 견적서 → 계약 체크 질문 → 범위 밖 요청 대응 → 납품·검수 → 정산까지 순서대로.
계약 효력과 세금은 공식 안내와 전문가가 기준입니다.

  • 진행 중에 "이것도 하나만 더"가 계속 늘어난다
  • 납품했는데 "조금만 더 고치면" 하며 잔금이 밀린다

4단계 셀프 문서 순서

내 상품·가격 — 작업을 기본 단위로 쪼개고, 연습 작업 시간을 재서 '시간 × 시간당 금액 + 비용' 계산식으로 3단계 가격표를 만듭니다.
문의·범위 — 문의를 AI로 분석해 빠진 정보를 질문으로 묻고, 결과물·수정 1회 정의·완료 기준·'안 하는 일'을 적은 업무 범위서를 먼저 합의합니다.
견적·계약 — 범위를 붙인 견적서를 보내고, 가격 조정은 범위로 응대합니다. 계약은 범위·수정·검수·대금·권리 5가지를 질문으로 확인합니다.
진행·정산 — 착수 확인 메시지, 진행 보고, 범위 밖 요청은 추가 견적으로, 납품 후 검수 요청, 잔금 요청과 정중한 독촉 단계, 정산 장부까지.
