부모님 치과 치료를 함께 알아보는 자녀

부모님 첫 임플란트·틀니, 무엇을 묻고 확인할까
상담 질문부터 형제 분담까지 한 장씩

무료 AI를 어떤 치료가 맞는지 판단하는 도구가 아니라 치과 상담 질문지·들은 설명 정리·견적 비교표·건강보험 확인 질문을 만드는 정리 비서로 씁니다. 상담 전 준비 → 치과 상담 → 견적·건강보험·계약 확인 → 가족 결정과 치료 시작 → 치료 중 관리 → 비용 기록·형제 분담·정기검진까지 순서대로.
진단은 치과의사, 결정은 부모님입니다.

혹시 이런 상태인가요?

  • 부모님이 식사를 불편해하시는데, 치과에서 무엇을 물어야 할지 모르겠다
  • 치과마다 설명과 견적이 달라서 무엇을 비교해야 할지 모르겠다
  • 건강보험이 되는지, 무엇이 빠지는지 헷갈린다
  • 형제끼리 비용과 동행을 어떻게 나눌지 이야기를 못 꺼내고 있다

자녀 정리 순서

상담 전 준비 — 부모님·가족 상황 프로필, 부모님 말씀 그대로 적는 불편한 점·식사 기록, '결정은 부모님 먼저'로 시작하는 우리 집 치과 비용 원칙, 치과 후보와 비급여 진료비·공단 확인 계획.
치과 상담 — 치과의사께 여쭐 상담 질문지, 들은 그대로 적는 당일 기록, 형제 공유 요약과 부모님과 대화, 들은 설명 6칸 정리.
견적·건강보험·계약 확인 — 포함 항목부터 맞추는 견적 비교표, 항목별 질문, 건강보험 적용 확인(치과용·공단용 질문 분리), 결제 시점·치료비용계획서·나눠 내기 질문.
결정·치료·기록 — 부모님 뜻이 맨 위인 가족 결정 회의표, 서명·결제 전 확인, 내원 일정·동행표, 치과 안내·약 일정표, 식사·불편함 기록, 추가 비용 안내 때 질문, 비용·영수증 기록, 형제 비용 분담, 정기검진 달력·치과 정보 카드.

자주 묻는 질문

부모님께 임플란트가 맞는지 틀니가 맞는지 알려 주나요?
아니요. 진단하거나 치료 방법·개수·뼈이식을 판단하지 않습니다. 치과의사께 여쭐 질문을 준비하고 들은 설명을 정리·비교하는 데까지 돕습니다.
어느 치과가 좋은지 추천해 주나요?
추천하지 않습니다. 치과마다 들은 설명과 견적을 같은 칸에 적어 부모님과 가족이 직접 비교하도록 돕습니다.
건강보험이 되는지 알려 주나요?
공단이 안내한 기준 요지와 확인 질문을 드립니다. 부모님이 대상인지, 몇 개가 남았는지는 치과와 국민건강보험공단이 확인합니다.
파일은 어떻게 받나요?
결제 후 등급별 zip 파일을 받습니다. 개인 사용 목적이며 재판매·무단 배포는 금지됩니다.
